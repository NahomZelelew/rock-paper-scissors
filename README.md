# Rock, Paper, Scissors Game

A classic Rock, Paper, Scissors game built using clean HTML, CSS, and modern vanilla JavaScript. The project includes interactive emoji elements, persistent high-score tracking via browser storage, and an automated continuous gameplay loop.

## Features

- **Interactive UI:** Smooth transitions, dark mode background, and customized emoji icons for selections.
- **Persistent Scoring:** Keeps track of your total Wins, Losses, and Ties even if you refresh or close your browser page using `localStorage`.
- **Auto Play Mode:** Lets the computer automatically play simulated games against itself every 1 second.
- **Score Reset:** A single-button click clears out your total score history completely.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Run Locally

1. Clone this repository or download the source code files.
2. Open the `index.html` file inside any modern web browser.
